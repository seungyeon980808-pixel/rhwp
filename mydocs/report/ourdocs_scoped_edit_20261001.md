# OurDocs 영역 공유의 직접 입력 권한 보완

이 기록은 OurDocs 다운스트림 통합에 관한 것입니다. upstream 이슈·PR 작업은 생성하지 않았습니다.

## 변경

기존 live paste 정책의 epoch·허용 영역 목록을 직접 입력에도 적용합니다. 서버가 권한 밖의 수정을 거절하더라도 로컬 셀에 입력이 남던 경로를 차단합니다.

- 지원되는 본문 선택은 닿은 모든 문단의 권한을 확인합니다.
- 셀 안의 여러 문단은 셀 전체 권한 하나로 확인합니다.
- 서로 다른 셀·섹션을 잇는 텍스트 선택, 중첩 셀·글상자·머리말·각주·개체 선택은 지원 여부를 추정하지 않고 차단합니다.
- 일반 입력·IME 시작·입력 이벤트·Backspace·Delete와 실행 전 편집 명령에 같은 검사를 적용합니다.
- 이미 적용한 IME 편집의 이력 기록은 기존 동작대로 보존합니다.

## 검증

2026-10-01 Studio 타입 검사와 빌드 통과. Studio Node 테스트는 1,160개 통과, 1개 건너뜀입니다. 새 선택 범위 테스트는 본문 순서·역순, 같은 셀의 여러 문단, 지원하지 않는 선택을 검증합니다.

OurDocs 실제 브라우저 드라이버에서 Chromium·WebKit으로 영역 초대를 받은 참여자의 허용 셀 입력·문서 저장을 확인했습니다. 권한 밖의 셀 입력·Backspace·Delete·composition 이벤트에서는 문서가 바뀌지 않았습니다. 서버 직접 조작 요청도 거절됐습니다. 시험 문서는 삭제했습니다.

재실행 드라이버는 상위 OurDocs 저장소의 `scripts/ourdocs-drag-share-qa.mts`에 있습니다. 실제 Safari 앱 및 실제 한글 입력기의 수동 검증은 수행하지 않았습니다. Rust 소스는 변경하지 않았습니다.
